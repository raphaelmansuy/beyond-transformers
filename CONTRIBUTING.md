# Contributing

Thank you for helping improve the companion code for *Beyond Transformers*.

## Scope

This repository holds **chapter scaffolds, running examples, and evaluation templates** — not the full Packt manuscript. Prefer small, runnable stubs that demonstrate one idea clearly.

## How to contribute

1. Open an issue describing the gap (missing stub, unclear README, broken path).
2. Fork and create a branch named `chapter-NN/short-desc` or `examples/short-desc`.
3. Keep chapter READMEs simple: what you learn, the example you build, how to run.
4. Mark unfinished scripts with `# stub` and a one-line comment of intended behavior.
5. Do not invent benchmark numbers; use the Invoice Impact template for before/after notes.
6. Open a pull request against `main`.

## Code style

- Python 3.11+ preferred.
- Minimal dependencies in early chapters; document extras in the chapter README.
- Prefer clarity over cleverness — readers are learning architectures, not frameworks.
