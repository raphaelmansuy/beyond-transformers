# Chapter 2 — The Architectural Taxonomy of 2026

## What this chapter teaches

- Three families: **Generative**, **Predictive**, and **Energy-Based**.
- A practical decision framework for choosing inductive bias (context shape, state, structure, inference budget).
- How the four running examples map onto that taxonomy.
- Where triage ends and measurement (Invoice Impact) begins.

## Example you build

**`triage.py`** — a small CLI that asks the framework questions and prints a first-candidate family plus which running example to touch. See also [`examples/architecture-decision-framework.md`](../../examples/architecture-decision-framework.md).

## How to run

```bash
python examples/chapter-02/triage.py   # stub
```
